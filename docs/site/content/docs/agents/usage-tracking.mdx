---
title: Usage & rate-limit tracking
---

Orca reads provider usage state for Claude Code, Codex, Gemini, OpenCode, Kimi Code, and MiniMax and surfaces it in the status bar, so you know how close you are to a rate limit before an agent stalls. Codex can also report the active account's monthly credit usage.

## What's shown

- Current usage against the active account's plan.
- Time to reset for 5-hour, daily, weekly, and Claude Fable weekly windows (where applicable).
- Active-account Codex monthly credits when the authenticated provider reports them.
- A warning chip when you cross 80% of a limit.

## How it works

Provider rate limits and Codex monthly credits use the credentials already configured for the active agent account. Orca never asks for a separate API key. Codex analytics are a separate opt-in local scan of rollout logs under Orca-managed and system Codex homes.

Provider values are authoritative but can be unavailable when the provider changes its private usage response. Local estimates use standard published token rates, do not infer Fast-mode multipliers, and cannot include cloud or other-device usage. They are only shown when Codex Usage Tracking is enabled, cover local accounts on this machine, and are labeled as estimates.

## Multi-account accounting

The status bar always reflects the _active_ account. Other configured accounts are visible in the account switcher with their own usage.

## Usage roster

Click the usage segment in the status bar to open the **Usage** popover. It lists every tracked provider (icon · name · plan · soonest reset · per-window bars), sorted so the tightest limit is first. Codex rows identify whether the value belongs to the **Active account** or is a **Local accounts · estimated** fallback. Use the header refresh control to re-read provider and local usage state.

- **Detailed** — full bars, labels, and percentages for every window
- **Compact** — only the tightest window per provider

Under [Settings → Appearance](/docs/settings), choose **% used** vs **% remaining** for how those numbers read.

Rows without live numbers show a short status instead: **Loading usage…**, **not signed in**, **Usage unavailable**, **No usage data**, or a provider-specific error. Claude and Codex rows can drill into account switching; **Manage accounts** opens Settings.

### Mobile

On the companion app, open the host **Accounts** screen for the same switcher/usage readout. When Codex has earned **rate-limit reset** credits, spend one from that screen (see [Mobile companion](/docs/mobile)).

## Estimated cost (Stats)

The Stats breakdown may show **estimated cost** for known model families (including Claude 5-class and Codex GPT-5.6 rows). Rows marked **• inferred pricing** use Orca’s local price table, not a live bill from the provider. Prefer the provider console for authoritative spend.
